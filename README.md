# Kitchen Utility

A collection of cooking tools for the home cook. Built as a single-page app with vanilla HTML, CSS, and JavaScript. Hosted on GitHub Pages.

## Tools

- **Dough Calculator** — Baker's percentages, hydration, salt, starter ratios
- **Recipe Scaler** — Scale any recipe up or down by servings
- **Cooking Timer** — Multi-timer with audio alerts for coordinating multiple dishes
- **Unit Converter** — Temperature (°C/°F/K), volume (ml/cups/tbsp), weight (g/oz/lb)
- **Substitution Finder** — Common ingredient substitutions with ratios and notes

## Usage

Open `index.html` in any modern browser. No build step required.

## Deploy to GitHub Pages

1. Push this repo to GitHub
2. Go to Settings → Pages
3. Select branch: main, folder: / (root)
4. Your site will be available at `https://<username>.github.io/<repo-name>`
